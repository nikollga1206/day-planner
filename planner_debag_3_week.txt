Приложен planner.html — работающий планировщик «спираль суток». Логику 
углов, пересечений и однодневный формат экспорта JSON НЕ менять. 
Добавь расписания по дням:

1. Переключатель дней недели (Пн–Вс) над спиралей: у каждого дня своё 
   расписание. Сейчас заполненный день скопируй во все семь как стартовую 
   точку.
2. Хранение в localStorage: все семь дней. Общая библиотека постоянных 
   задач остаётся единой для всех дней.
3. Кнопка «Скопировать расписание на...» — копирует текущий день в 
   выбранные дни (например, Пн → Вт, Ср, Чт, Пт).
4. ЭКСПОРТ: две кнопки. «Экспорт дня» — выбранный день в ПРЕЖНЕМ формате 
   JSON (его читает внешний агент, формат зафиксирован). «Экспорт всех 
   дней» — полный файл резервной копии. Импорт соответственно оба.
5. Задокументируй обе структуры комментарием в коде.

КОНТРОЛЬ: прежний тест углов и суммы 1440 мин на каждом дне; экспорт дня 
даёт файл старого формата; переключение дней не теряет данные после 
перезагрузки страницы.
