2. Для outer-level labels генерируй невидимый <path> (дуга окружности) с уникальным id. Дуга должна:
   - Радиус: R_LABEL_OUTER = (R_BAND + R_OUTER) / 2 (середина кольца)
   - Идти от startAngle до endAngle сегмента с отступом ~1° с каждого края
   - Использовать команду SVG path: M x1 y1 A rx ry 0 large-arc-flag sweep-flag x2 y2

3. Направление дуги для outer level:

   - НЕ используй rotate(180) или transform flip для textPath — направление дуги само решает проблему перевёрнутости

4. Атрибуты textPath:
   - href="#уникальный-id"
   - startOffset="50%"
   - method="align"
   - spacing="auto"
   - На родительском <text> оставь text-anchor="middle", dominant-baseline="middle"
